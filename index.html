Documentación Técnica del Compilador

Analizador estático léxico, sintáctico y semántico para el lenguaje DSL de control de Brazo Robótico.

1. Visión General del Proyecto

Este compilador fue desarrollado como el motor de validación para una interfaz de programación de un brazo robótico articulado (basado en servomotores y controladores ESP32). Su objetivo central es procesar el código de control, detectar inconsistencias léxicas, errores sintácticos de bloques/delimitadores y validar límites físicos semánticos (ángulos fuera de rango, tipos de datos e instrucciones inexistentes) antes de enviar la transmisión de comandos al microcontrolador.

2. Tecnologías y Herramientas

JavaScript (Node.js/Web)

Utilizado en la etapa inicial de prototipado rápido para integrar el compilador directamente con la interfaz gráfica web del IDE.

C++ (C++11 / C++17)

Lenguaje de producción definitivo para garantizar ejecución de alta velocidad, administración precisa de memoria y portabilidad a sistemas embebidos.

Hardware y Simulación

Integración conceptual con microcontroladores ESP32, simulador Wokwi y servomotores con rangos físicos delimitados (0° a 180°).

3. Arquitectura del Sistema

1. Lexer (Léxico)

Convierte el flujo de caracteres en tokens. Incluye manejo especial de UTF-8 para interceptar caracteres no válidos (acentos) sin interrumpir el parseo.

2. Parser (Sintáctico)

Verifica la estructura gramatical, balance de corchetes [...], paréntesis (...) y sintaxis de condicionales (si, sino, repetir).

3. Semántico

Mantiene la Tabla de Símbolos, valida compatibilidad de tipos (VARNUM vs VARTEXTO), límites de servomotores y funciones no declaradas.

5. Reglas de Validación Detectadas

LÉXICO Caracteres No Permitidos (UTF-8)

Captura caracteres fuera del alfabeto permitido (como vocales con acento 'á', 'é' o caracteres especiales) informando la columna y línea exacta sin detener abruptamente el escaneo.

SINTÁCTICO Estructuras de Control y Delimitadores

Valida la presencia obligatoria de paréntesis en la condición de si(...) o repetir(...) y exige apertura de bloques con corchete [ en el sino.

SEMÁNTICO Rango Físico de Servomotores (0° a 180°)

Evalúa los argumentos pasados a funciones como moverBase() o moverGarra(). Si el valor es negativo o supera 180, emite una alerta semántica.

SEMÁNTICO Incompatibilidad de Tipos y Firmas

Impide asignaciones entre VARNUM y VARTEXTO, previene operaciones incoherentes y verifica las firmas de funciones.

struct Token {
    std::string type;
    std::string value;
    int line;
    int column;
    double numValue;

    Token(std::string t, std::string v, int l, int c, double nv = 0.0)
        : type(t), value(v), line(l), column(c), numValue(nv) {}
};

struct DiagnosticError {
    int line;
    int column;
    std::string category; // LEXICO, SINTACTICO, SEMANTICO
    std::string message;
};

// ==========================================
// 2. ANALIZADOR LÉXICO (LEXER)
// ==========================================

class Lexer {
private:
    std::string source;
    size_t cursor;
    int line;
    int column;
    std::vector<DiagnosticError>& errors;

    const std::unordered_set<std::string> keywords = {
        "INICIO", "BUCLE", "VARNUM", "VARTEXTO", "BOOLEANOS", "si", "sino", "repetir"
    };

    const std::unordered_set<std::string> robotFunctions = {
        "moverBase", "moverHombro", "moverCodo", "moverMuneca", "moverGarra",
        "Limpiar", "escribir", "LED", "sonar", "esperar", "Adelante", "Atras", 
        "Detener", "velocidadBanda", "LeerSensor"
    };

public:
    Lexer(const std::string& src, std::vector<DiagnosticError>& errs)
        : source(src), cursor(0), line(1), column(1), errors(errs) {}

    std::vector<Token> tokenize() {
        std::vector<Token> tokens;

        while (cursor < source.length()) {
            char current = source[cursor];

            if (current == ' ' || current == '\t' || current == '\r') {
                advance();
                continue;
            }

            if (current == '\n') {
                line++;
                column = 1;
                cursor++;
                continue;
            }

            // Comentarios con @
            if (current == '@') {
                while (cursor < source.length() && source[cursor] != '\n') {
                    advance();
                }
                continue;
            }

            // Cadenas de texto
            if (current == '"') {
                int startCol = column;
                advance();
                std::string text = "";
                while (cursor < source.length() && source[cursor] != '"' && source[cursor] != '\n') {
                    text += source[cursor];
                    advance();
                }
                if (cursor < source.length() && source[cursor] == '"') {
                    advance();
                    tokens.push_back(Token("LITERAL_TEXTO", text, line, startCol));
                } else {
                    errors.push_back({line, startCol, "LEXICO", "Cadena de texto sin cerrar con comillas."});
                }
                continue;
            }

            // Números (Positivos y Negativos)
            if (std::isdigit(current) || (current == '-' && cursor + 1 < source.length() && std::isdigit(source[cursor + 1]))) {
                int startCol = column;
                std::string numStr = "";
                if (current == '-') {
                    numStr += current;
                    advance();
                }
                while (cursor < source.length() && (std::isdigit(source[cursor]) || source[cursor] == '.')) {
                    numStr += source[cursor];
                    advance();
                }
                tokens.push_back(Token("NUMERO", numStr, line, startCol, std::stod(numStr)));
                continue;
            }

            // Identificadores, Palabras Reservadas y Funciones (Soporte UTF-8 / Acentos)
            if (std::isalpha((unsigned char)current) || current == '_') {
                int startCol = column;
                std::string id = "";
                bool tieneCaracterInvalido = false;

                while (cursor < source.length()) {
                    unsigned char ch = source[cursor];
                    
                    if (std::isspace(ch) || ch == '(' || ch == ')' || ch == '[' || 
                        ch == ']' || ch == ',' || ch == '=' || ch == ';' || ch == '$' || ch == '#') {
                        break;
                    }

                    if (ch > 127) {
                        if (!tieneCaracterInvalido) {
                            errors.push_back({line, column, "LEXICO", "Caracter no permitido en el alfabeto (acento/especial)"});
                            tieneCaracterInvalido = true;
                        }
                        advance();
                        continue;
                    }

                    id += (char)ch;
                    advance();
                }

                if (!tieneCaracterInvalido && !id.empty()) {
                    if (keywords.find(id) != keywords.end()) {
                        tokens.push_back(Token("PALABRA_RESERVADA", id, line, startCol));
                    } else if (robotFunctions.find(id) != robotFunctions.end()) {
                        tokens.push_back(Token("FUNCION", id, line, startCol));
                    } else {
                        tokens.push_back(Token("ID", id, line, startCol));
                    }
                }
                continue;
            }

            // Delimitadores y Operadores
            if (current == '[' || current == ']' || current == '(' || current == ')' || current == ',') {
                tokens.push_back(Token("DELIMITADOR", std::string(1, current), line, column));
                advance();
                continue;
            }

            if (current == '=' || current == '<' || current == '>' || current == '+' || current == '-') {
                int startCol = column;
                std::string op(1, current);
                advance();
                if (cursor < source.length() && source[cursor] == '=') {
                    op += '=';
                    advance();
                }
                tokens.push_back(Token("OPERADOR", op, line, startCol));
                continue;
            }

            errors.push_back({line, column, "LEXICO", std::string("Simbolo no perteneciente al alfabeto: '") + current + "'"});
            advance();
        }

        return tokens;
    }

private:
    void advance() {
        cursor++;
        column++;
    }
};

// 3. ANALIZADOR SINTÁCTICO Y SEMÁNTICO
// ==========================================

class Compiler {
private:
    std::vector<Token> tokens;
    size_t cursor;
    std::vector<DiagnosticError>& errors;
    std::unordered_map<std::string, std::string> symbolTable;

    const std::unordered_set<std::string> validFunctions = {
        "moverBase", "moverHombro", "moverCodo", "moverMuneca", "moverGarra",
        "Limpiar", "escribir", "LED", "sonar", "esperar", "Adelante", "Atras", 
        "Detener", "velocidadBanda", "LeerSensor"
    };

public:
    Compiler(const std::vector<Token>& t, std::vector<DiagnosticError>& errs)
        : tokens(t), cursor(0), errors(errs) {}

    bool analyze() {
        checkBalancing();

        while (cursor < tokens.size()) {
            Token tok = peek();

            // Delimitadores de bloque o keywords de bloque
            if (tok.value == "[" || tok.value == "]" || tok.value == "INICIO" || tok.value == "BUCLE") {
                advance();
                continue;
            }

            // Declaración de Variables
            if (tok.type == "PALABRA_RESERVADA" && (tok.value == "VARNUM" || tok.value == "VARTEXTO" || tok.value == "BOOLEANOS")) {
                parseDeclaration();
                continue;
            }

            // Llamadas a Funciones
            if (tok.type == "FUNCION") {
                parseFunctionCall();
                continue;
            }

            // Asignación o Uso de Variables / Llamadas a funciones no declaradas
            if (tok.type == "ID") {
                if (cursor + 1 < tokens.size() && tokens[cursor + 1].value == "(") {
                    // Función inexistente en la especificación del lenguaje
                    errors.push_back({tok.line, tok.column, "SEMANTICO", "Uso de funcion no definida en el lenguaje: '" + tok.value + "()'"});
                    advance(); // Consumir ID
                    parseFunctionCall();
                } else {
                    parseAssignmentOrUsage();
                }
                continue;
            }

            // Estructuras de Control 'si'
            if (tok.type == "PALABRA_RESERVADA" && tok.value == "si") {
                advance(); // Consumir 'si'
                if (peek().value != "(") {
                    errors.push_back({tok.line, tok.column, "SINTACTICO", "Falta de parentesis '(' en la condicion del 'si'"});
                } else {
                    advance(); // Consumir '('
                    
                    // Verificar procedimiento sin retorno dentro de la condición
                    if (peek().type == "FUNCION" && peek().value == "sonar") {
                        errors.push_back({peek().line, peek().column, "SEMANTICO", "Uso de procedimiento sin retorno 'sonar()' dentro de una condicion relacional"});
                    }

                    parseExpression();
                    if (peek().value == ")") advance();
                }
                continue;
            }

            // Estructura 'sino'
            if (tok.type == "PALABRA_RESERVADA" && tok.value == "sino") {
                advance(); // Consumir 'sino'
                if (peek().value != "[") {
                    errors.push_back({tok.line, tok.column, "SINTACTICO", "Estructura incorrecta en 'sino': Se esperaba '[' para abrir el bloque"});
                }
                continue;
            }

            // Estructura 'repetir'
            if (tok.type == "PALABRA_RESERVADA" && tok.value == "repetir") {
                advance(); // Consumir 'repetir'
                if (peek().value != "(") {
                    errors.push_back({tok.line, tok.column, "SINTACTICO", "Inversion de delimitadores o falta de '(' en la instruccion 'repetir'"});
                } else {
                    advance();
                    parseExpression();
                    if (peek().value == ")") advance();
                }
                continue;
            }

            advance();
        }

        return errors.empty();
    }

private:
    Token peek() {
        if (cursor < tokens.size()) return tokens[cursor];
        return Token("EOF", "", -1, -1);
    }

    Token advance() {
        Token t = peek();
        if (cursor < tokens.size()) cursor++;
        return t;
    }

    void parseDeclaration() {
        Token typeTok = advance(); // Consumir VARNUM / VARTEXTO / BOOLEANOS
        Token idTok = peek();

        if (idTok.type == "ID") {
            advance(); // Consumir nombre de la variable
            symbolTable[idTok.value] = typeTok.value; // Registrar en tabla de símbolos

            if (peek().value == "=") {
                advance(); // Consumir '='
                std::string exprType = parseExpression();
                if (exprType != "DESCONOCIDO" && typeTok.value == "VARNUM" && exprType == "VARTEXTO") {
                    errors.push_back({idTok.line, idTok.column, "SEMANTICO", "Incompatibilidad de tipos: No se puede asignar VARTEXTO a " + typeTok.value + " '" + idTok.value + "'"});
                }
            }
        } else {
            errors.push_back({typeTok.line, typeTok.column, "SINTACTICO", "Se esperaba un identificador despues de " + typeTok.value});
        }
    }

    void parseAssignmentOrUsage() {
        Token idTok = advance(); // Consumir el ID

        if (symbolTable.find(idTok.value) == symbolTable.end()) {
            errors.push_back({idTok.line, idTok.column, "SEMANTICO", "Variable no declarada: '" + idTok.value + "'"});
        }

        if (peek().value == "=") {
            advance(); // Consumir '='
            std::string varType = symbolTable[idTok.value];
            std::string exprType = parseExpression();

            if (varType == "VARNUM" && exprType == "VARTEXTO") {
                errors.push_back({idTok.line, idTok.column, "SEMANTICO", "Incompatibilidad de tipos: Intentando asignar VARTEXTO a la variable VARNUM '" + idTok.value + "'"});
            }
        }
    }

    void parseFunctionCall() {
        Token funcTok = advance(); // Consumir la función

        if (peek().value == "(") {
            advance(); // Consumir '('
            std::vector<Token> args;

            while (cursor < tokens.size() && peek().value != ")" && peek().value != "]") {
                Token t = peek();

                if (t.type == "ID") {
                    if (symbolTable.find(t.value) == symbolTable.end()) {
                        errors.push_back({t.line, t.column, "SEMANTICO", "Variable no declarada: '" + t.value + "'"});
                    } else {
                        // Pasar tipo guardado en tabla
                        t.type = symbolTable[t.value];
                    }
                    args.push_back(t);
                    advance();
                } else if (t.type == "FUNCION") {
                    parseFunctionCall();
                } else if (t.type == "NUMERO" || t.type == "LITERAL_TEXTO") {
                    args.push_back(t);
                    advance();
                } else {
                    advance();
                }

                if (peek().value == ",") {
                    advance(); // Consumir coma
                }
            }

            if (peek().value == ")") {
                advance(); // Consumir ')'
            }

            // 1. Validar límites de ángulos en servomotores (0 a 180)
            if (funcTok.value == "moverBase" || funcTok.value == "moverHombro" || 
                funcTok.value == "moverCodo" || funcTok.value == "moverMuneca" || funcTok.value == "moverGarra") {
                if (!args.empty() && args[0].type == "NUMERO") {
                    if (args[0].numValue < 0 || args[0].numValue > 180) {
                        errors.push_back({funcTok.line, funcTok.column, "SEMANTICO", 
                            "Angulo fuera de rango (0 a 180) en " + funcTok.value + ": " + std::to_string((int)args[0].numValue)});
                    }
                }
            }

            // 2. Validar firma de la función escribir(x, y, tam, msg)
            if (funcTok.value == "escribir") {
                if (args.size() == 4) {
                    bool p1Valido = (args[0].type == "NUMERO" || args[0].type == "VARNUM");
                    bool p2Valido = (args[1].type == "NUMERO" || args[1].type == "VARNUM");
                    bool p3Valido = (args[2].type == "NUMERO" || args[2].type == "VARNUM");
                    bool p4Valido = (args[3].type == "LITERAL_TEXTO" || args[3].type == "VARTEXTO");

                    if (!p1Valido || !p2Valido || !p3Valido || !p4Valido) {
                        errors.push_back({funcTok.line, funcTok.column, "SEMANTICO", 
                            "Incompatibilidad de parametros en escribir(): Requiere (VARNUM, VARNUM, VARNUM, VARTEXTO)"});
                    }
                }
            }
        }
    }

    std::string parseExpression() {
        std::string primaryType = "DESCONOCIDO";
        bool hayNumero = false;
        bool hayTexto = false;
        int lineErr = peek().line;
        int colErr = peek().column;

        while (cursor < tokens.size()) {
            Token t = peek();

            if (t.value == "]" || t.value == ")" || t.value == "," || 
                t.type == "PALABRA_RESERVADA" || t.value == "sino") {
                break;
            }

            if (t.type == "LITERAL_TEXTO") {
                hayTexto = true;
                if (primaryType == "DESCONOCIDO") primaryType = "VARTEXTO";
                advance();
            } else if (t.type == "NUMERO") {
                hayNumero = true;
                if (primaryType == "DESCONOCIDO") primaryType = "VARNUM";
                advance();
            } else if (t.type == "ID") {
                if (symbolTable.find(t.value) == symbolTable.end()) {
                    errors.push_back({t.line, t.column, "SEMANTICO", "Variable no declarada: '" + t.value + "'"});
                } else {
                    std::string realType = symbolTable[t.value];
                    if (realType == "VARNUM") hayNumero = true;
                    if (realType == "VARTEXTO") hayTexto = true;
                    if (primaryType == "DESCONOCIDO") primaryType = realType;
                }
                advance();
            } else if (t.type == "FUNCION") {
                parseFunctionCall();
            } else {
                advance();
            }
        }

        // Operación aritmética incoherente entre número y cadena
        if (hayNumero && hayTexto) {
            errors.push_back({lineErr, colErr, "SEMANTICO", "Operacion aritmetica incoherente entre un numero (VARNUM) y una cadena (VARTEXTO)"});
        }

        return primaryType;
    }

    void checkBalancing() {
        int brackets = 0, parens = 0;
        for (const auto& tok : tokens) {
            if (tok.value == "[") brackets++;
            if (tok.value == "]") brackets--;
            if (tok.value == "(") parens++;
            if (tok.value == ")") parens--;
        }
        if (brackets != 0) errors.push_back({(int)tokens.size(), 1, "SINTACTICO", "Falta de cierre de bloque principal / Error de balanceo en corchetes '[' o ']'"});
        if (parens != 0) errors.push_back({(int)tokens.size(), 1, "SINTACTICO", "Error de balanceo en parentesis '(' o ')'"});
    }
};

int main() {
    std::string codigoFuente = R"(
@ Ejemplo 1: Control Basico del Sistema (~50 lineas)

INICIO [
    VARNUM anguloHome = 90
    VARNUM garraAbierta = 0
    VARNUM garraCerrada = 180
    VARNUM frecuenciaTono = 880
    BOOLEANOS estadoSensor = 0

    @ Mensaje de arranque en OLED
    Limpiar()
    escribir(0, 0, 1, "Iniciando Test")

    @ Calibrar brazo a posicion base
    moverBase(anguloHome)
    moverHombro(anguloHome)
    moverCodo(anguloHome)
    moverMuneca(anguloHome)
    moverGarra(garraAbierta)

    @ Indicar estado con LED verde
    LED(0, 255, 0)
    sonar(frecuenciaTono)
    esperar(300)
    sonar(0)

    Limpiar()
    escribir(0, 0, 1, "Sistema Listo")
]

BUCLE [
    estadoSensor = LeerSensor()

    si (estadoSensor == 1) [
        LED(255, 0, 0)
        Limpiar()
        escribir(0, 0, 1, "Objeto Cerca")
        
        moverGarra(garraCerrada)
        esperar(500)
        moverGarra(garraAbierta)
        esperar(500)
        
        LED(0, 255, 0)
    ] sino [
        Limpiar()
        escribir(0, 0, 1, "Esperando...")
        esperar(200)
    ]
]
)";

    std::cout << "====================================================\n";
    std::cout << "        COMPILADOR IDE BRAZO ROBÓTICO (C++)         \n";
    std::cout << "====================================================\n\n";

    std::vector<DiagnosticError> diagnosticos;

    // 1. Análisis Léxico
    Lexer lexer(codigoFuente, diagnosticos);
    std::vector<Token> tokens = lexer.tokenize();

    // 2. Análisis Sintáctico y Semántico
    Compiler compiler(tokens, diagnosticos);
    compiler.analyze();

    std::cout << "--- [ CONSOLA DE DIAGNÓSTICO ] ---\n";
    if (diagnosticos.empty()) {
        std::cout << "[ÉXITO] Código compilado exitosamente.\n";
    } else {
        std::cout << "[ERROR] Se encontraron " << diagnosticos.size() << " error(es) en el código:\n\n";
        for (const auto& err : diagnosticos) {
            std::cout << " -> Linea " << err.line << ", Col " << err.column 
                      << " [" << err.category << "]: " << err.message << "\n";
        }
    }
    std::cout << "====================================================\n";

    return 0;
}

const KEYWORDS = [
    'INICIO', 'BUCLE', 'VARNUM', 'VARTEXTO', 'BOOLEANOS',
    'si', 'sino', 'repetir'
];

const FUNCTIONS = [
    'moverBase', 'moverHombro', 'moverCodo', 'moverMuneca', 'moverGarra',
    'esperar', 'sonar', 'Limpiar', 'escribir', 'LED',
    'LeerSensor', 'Adelante', 'Atras', 'Detener', 'EstadoMotor', 'velocidadBanda'
];

const OPERATORS = [
    '==', '!=', '<=', '>=', '=', '<', '>', '+', '-', '*', '/', '!', '|', '&'
];

const DELIMITERS = ['(', ')', '[', ']', ','];

class LexerJS {
    constructor(source) {
        this.source = source;
        this.tokens = [];
        this.errors = [];
        this.line = 1;
        this.column = 1;
        this.cursor = 0;
    }

    tokenize() {
        while (this.cursor < this.source.length) {
            const char = this.source[this.cursor];

            if (char === '\n') {
                this.line++;
                this.column = 1;
                this.cursor++;
                continue;
            }

            if (/\s/.test(char)) {
                this.column++;
                this.cursor++;
                continue;
            }

            if (char === '@') {
                while (this.cursor < this.source.length && this.source[this.cursor] !== '\n') {
                    this.cursor++;
                }
                continue;
            }

            if (char === '"') {
                let startCol = this.column;
                let str = '';
                this.cursor++;
                this.column++;

                while (this.cursor < this.source.length && this.source[this.cursor] !== '"' && this.source[this.cursor] !== '\n') {
                    str += this.source[this.cursor];
                    this.cursor++;
                    this.column++;
                }

                if (this.source[this.cursor] === '"') {
                    this.cursor++;
                    this.column++;
                    this.tokens.push({ type: 'LITERAL_TEXTO', value: str, line: this.line, column: startCol });
                } else {
                    this.errors.push({ type: 'Léxico', msg: 'Cadena de texto sin cerrar con comillas', line: this.line, column: startCol });
                }
                continue;
            }

            const twoCharOp = this.source.substring(this.cursor, this.cursor + 2);
            if (['==', '!=', '<=', '>='].includes(twoCharOp)) {
                this.tokens.push({ type: 'OPERADOR', value: twoCharOp, line: this.line, column: this.column });
                this.cursor += 2;
                this.column += 2;
                continue;
            }

            if (OPERATORS.includes(char)) {
                this.tokens.push({ type: 'OPERADOR', value: char, line: this.line, column: this.column });
                this.cursor++;
                this.column++;
                continue;
            }

            if (DELIMITERS.includes(char)) {
                this.tokens.push({ type: 'DELIMITADOR', value: char, line: this.line, column: this.column });
                this.cursor++;
                this.column++;
                continue;
            }

            if (/[0-9]/.test(char)) {
                let startCol = this.column;
                let numStr = '';
                while (this.cursor < this.source.length && /[0-9]/.test(this.source[this.cursor])) {
                    numStr += this.source[this.cursor];
                    this.cursor++;
                    this.column++;
                }
                this.tokens.push({ type: 'LITERAL_NUMERO', value: parseInt(numStr, 10), line: this.line, column: startCol });
                continue;
            }

            if (/[a-zA-Z_]/.test(char)) {
                let startCol = this.column;
                let id = '';
                while (this.cursor < this.source.length && /[a-zA-Z0-9_]/.test(this.source[this.cursor])) {
                    id += this.source[this.cursor];
                    this.cursor++;
                    this.column++;
                }

                if (KEYWORDS.includes(id)) {
                    this.tokens.push({ type: 'PALABRA_RESERVADA', value: id, line: this.line, column: startCol });
                } else if (FUNCTIONS.includes(id)) {
                    this.tokens.push({ type: 'FUNCION', value: id, line: this.line, column: startCol });
                } else {
                    this.tokens.push({ type: 'ID', value: id, line: this.line, column: startCol });
                }
                continue;
            }

            this.errors.push({
                type: 'Léxico',
                msg: `Carácter no reconocido '${char}' en el alfabeto.`,
                line: this.line,
                column: this.column
            });
            this.cursor++;
            this.column++;
        }

        return { tokens: this.tokens, errors: this.errors };
    }
}

class CompilerJS {
    constructor(tokens) {
        this.tokens = tokens;
        this.cursor = 0;
        this.errors = [];
        this.symbolTable = {};
    }

    peek() {
        return this.tokens[this.cursor] || null;
    }

    consume(expectedValue = null, expectedType = null) {
        const token = this.peek();
        if (!token) {
            this.errors.push({ type: 'Sintáctico', msg: 'Fin inesperado del archivo (EOF)', line: 'Fin', column: 0 });
            return null;
        }

        if (expectedValue && token.value !== expectedValue) {
            this.errors.push({
                type: 'Sintáctico',
                msg: `Se esperaba '${expectedValue}', pero se encontró '${token.value}'`,
                line: token.line,
                column: token.column
            });
            return null;
        }

        if (expectedType && token.type !== expectedType) {
            this.errors.push({
                type: 'Sintáctico',
                msg: `Se esperaba un tipo ${expectedType}, pero se encontró '${token.value}'`,
                line: token.line,
                column: token.column
            });
            return null;
        }

        this.cursor++;
        return token;
    }

    compile() {
        if (this.tokens.length === 0) return { errors: this.errors, symbolTable: this.symbolTable };

        let hasInicio = false;
        let hasBucle = false;

        while (this.cursor < this.tokens.length) {
            const token = this.peek();

            if (token.value === 'INICIO') {
                hasInicio = true;
                this.consume('INICIO');
                this.consume('[', 'DELIMITADOR');
                this.parseBlock();
            } else if (token.value === 'BUCLE') {
                hasBucle = true;
                this.consume('BUCLE');
                this.consume('[', 'DELIMITADOR');
                this.parseBlock();
            } else {
                this.errors.push({
                    type: 'Sintáctico',
                    msg: `Instrucción fuera de bloques INICIO o BUCLE: '${token.value}'`,
                    line: token.line,
                    column: token.column
                });
                this.cursor++;
            }
        }

        if (!hasInicio) this.errors.push({ type: 'Sintáctico', msg: 'Falta la estructura obligatoria INICIO [ ... ]', line: 1, column: 1 });
        if (!hasBucle) this.errors.push({ type: 'Sintáctico', msg: 'Falta la estructura obligatoria BUCLE [ ... ]', line: 1, column: 1 });

        return { errors: this.errors, symbolTable: this.symbolTable };
    }

    parseBlock() {
        while (this.cursor < this.tokens.length) {
            const token = this.peek();
            if (!token) break;

            if (token.value === ']') {
                this.consume(']');
                return;
            }

            this.parseStatement();
        }
    }

    parseStatement() {
        const token = this.peek();
        if (!token) return;

        if (['VARNUM', 'VARTEXTO', 'BOOLEANOS'].includes(token.value)) {
            this.parseDeclaration();
            return;
        }

        if (token.value === 'si') {
            this.parseSi();
            return;
        }

        if (token.value === 'repetir') {
            this.parseRepetir();
            return;
        }

        if (token.type === 'FUNCION') {
            this.parseFunctionCall();
            return;
        }

        if (token.type === 'ID') {
            this.parseAssignment();
            return;
        }

        this.errors.push({
            type: 'Sintáctico',
            msg: `Sentencia no reconocida: '${token.value}'`,
            line: token.line,
            column: token.column
        });
        this.cursor++;
    }

    parseDeclaration() {
        const typeToken = this.consume();
        const idToken = this.consume(null, 'ID');

        if (!idToken) return;

        if (this.symbolTable[idToken.value]) {
            this.errors.push({
                type: 'Semántico',
                msg: `La variable '${idToken.value}' ya ha sido declarada.`,
                line: idToken.line,
                column: idToken.column
            });
        }

        let initValue = null;

        if (this.peek() && this.peek().value === '=') {
            this.consume('=');
            const exprRes = this.parseExpression();
            initValue = exprRes ? exprRes.value : null;

            if (exprRes) {
                this.validateTypeCompatibility(typeToken.value, exprRes.type, idToken.line, idToken.column);
            }
        }

        this.symbolTable[idToken.value] = {
            type: typeToken.value,
            value: initValue !== null ? initValue : 'sin asignar',
            line: idToken.line
        };
    }

    parseAssignment() {
        const idToken = this.consume(null, 'ID');
        if (!idToken) return;

        if (!this.symbolTable[idToken.value]) {
            this.errors.push({
                type: 'Semántico',
                msg: `La variable '${idToken.value}' no ha sido declarada.`,
                line: idToken.line,
                column: idToken.column
            });
        }

        this.consume('=', 'OPERADOR');
        const exprRes = this.parseExpression();

        if (exprRes && this.symbolTable[idToken.value]) {
            const varType = this.symbolTable[idToken.value].type;
            this.validateTypeCompatibility(varType, exprRes.type, idToken.line, idToken.column);
            this.symbolTable[idToken.value].value = exprRes.value !== undefined ? exprRes.value : 'expresión';
        }
    }

    parseSi() {
        this.consume('si');
        this.consume('(', 'DELIMITADOR');
        const condRes = this.parseExpression();
        this.consume(')', 'DELIMITADOR');

        if (condRes && condRes.type !== 'BOOLEANOS' && condRes.type !== 'RELACIONAL') {
            this.errors.push({
                type: 'Semántico',
                msg: `La condición del 'si' debe evaluarse como Booleana.`,
                line: condRes.line,
                column: condRes.column
            });
        }

        this.consume('[', 'DELIMITADOR');
        this.parseBlock();

        if (this.peek() && this.peek().value === 'sino') {
            this.consume('sino');
            this.consume('[', 'DELIMITADOR');
            this.parseBlock();
        }
    }

    parseRepetir() {
        this.consume('repetir');
        this.consume('(', 'DELIMITADOR');
        const condRes = this.parseExpression();
        this.consume(')', 'DELIMITADOR');

        if (condRes && condRes.type !== 'BOOLEANOS' && condRes.type !== 'RELACIONAL') {
            this.errors.push({
                type: 'Semántico',
                msg: `La condición del bucle 'repetir' debe ser de tipo Booleano.`,
                line: condRes.line,
                column: condRes.column
            });
        }

        this.consume('[', 'DELIMITADOR');
        this.parseBlock();
    }

    parseFunctionCall() {
        const funcToken = this.consume(null, 'FUNCION');
        if (!funcToken) return;

        this.consume('(', 'DELIMITADOR');
        const args = [];

        while (this.peek() && this.peek().value !== ')') {
            const argExpr = this.parseExpression();
            if (argExpr) args.push(argExpr);

            if (this.peek() && this.peek().value === ',') {
                this.consume(',');
            } else {
                break;
            }
        }

        this.consume(')', 'DELIMITADOR');
        this.validateFunctionSemantics(funcToken, args);
    }

    validateFunctionSemantics(funcToken, args) {
        const fnName = funcToken.value;
        const servoFunctions = ['moverBase', 'moverHombro', 'moverCodo', 'moverMuneca', 'moverGarra'];

        if (servoFunctions.includes(fnName)) {
            if (args.length !== 1) {
                this.errors.push({
                    type: 'Semántico',
                    msg: `La función '${fnName}' requiere exactamente 1 argumento.`,
                    line: funcToken.line,
                    column: funcToken.column
                });
                return;
            }

            const arg = args[0];
            if (arg.type !== 'VARNUM') {
                this.errors.push({
                    type: 'Semántico',
                    msg: `El argumento de '${fnName}' debe ser numérico (VARNUM).`,
                    line: funcToken.line,
                    column: funcToken.column
                });
            } else if (typeof arg.value === 'number') {
                if (arg.value < 0 || arg.value > 180) {
                    this.errors.push({
                        type: 'Semántico',
                        msg: `Ángulo fuera de rango en '${fnName}(${arg.value})'. Permitido: 0° a 180°.`,
                        line: funcToken.line,
                        column: funcToken.column
                    });
                }
            }
        }

        if (fnName === 'LED') {
            if (args.length !== 3) {
                this.errors.push({
                    type: 'Semántico',
                    msg: `La función 'LED' requiere 3 parámetros: LED(R, G, B).`,
                    line: funcToken.line,
                    column: funcToken.column
                });
                return;
            }

            args.forEach((arg, index) => {
                const channels = ['R (Rojo)', 'G (Verde)', 'B (Azul)'];
                if (arg.type !== 'VARNUM') {
                    this.errors.push({
                        type: 'Semántico',
                        msg: `El canal ${channels[index]} de LED debe ser numérico.`,
                        line: funcToken.line,
                        column: funcToken.column
                    });
                } else if (typeof arg.value === 'number' && (arg.value < 0 || arg.value > 255)) {
                    this.errors.push({
                        type: 'Semántico',
                        msg: `Valor cromático fuera de rango en LED canal ${channels[index]}: '${arg.value}'. Rango [0 - 255].`,
                        line: funcToken.line,
                        column: funcToken.column
                    });
                }
            });
        }
    }

    parseExpression() {
        const token = this.peek();
        if (!token) return null;

        let left = null;

        if (token.type === 'LITERAL_NUMERO') {
            this.consume();
            left = { type: 'VARNUM', value: token.value, line: token.line, column: token.column };
        } else if (token.type === 'LITERAL_TEXTO') {
            this.consume();
            left = { type: 'VARTEXTO', value: token.value, line: token.line, column: token.column };
        } else if (token.type === 'ID') {
            this.consume();
            const varInfo = this.symbolTable[token.value];
            if (!varInfo) {
                this.errors.push({
                    type: 'Semántico',
                    msg: `Variable no declarada '${token.value}' en la expresión.`,
                    line: token.line,
                    column: token.column
                });
                left = { type: 'UNKNOWN', value: undefined, line: token.line, column: token.column };
            } else {
                left = { type: varInfo.type, value: varInfo.value, line: token.line, column: token.column };
            }
        } else if (token.type === 'FUNCION') {
            const fnName = token.value;
            this.parseFunctionCall();
            let returnType = 'VARNUM';
            if (fnName === 'LeerSensor' || fnName === 'EstadoMotor') returnType = 'BOOLEANOS';
            left = { type: returnType, value: 'retorno_func', line: token.line, column: token.column };
        }

        const nextToken = this.peek();
        if (nextToken && nextToken.type === 'OPERADOR') {
            const opToken = this.consume();
            this.parseExpression();

            if (['==', '!=', '<', '>', '<=', '>='].includes(opToken.value)) {
                return { type: 'RELACIONAL', value: 'boolean_res', line: opToken.line, column: opToken.column };
            }

            return { type: left ? left.type : 'VARNUM', value: 'calc_res', line: opToken.line, column: opToken.column };
        }

        return left;
    }

    validateTypeCompatibility(expectedType, actualType, line, col) {
        if (actualType === 'UNKNOWN') return;

        if (expectedType === 'BOOLEANOS' && actualType === 'VARNUM') return;
        if (expectedType === 'VARNUM' && actualType === 'BOOLEANOS') return;
        if (expectedType === 'RELACIONAL' && expectedType === 'BOOLEANOS') return;

        if (expectedType !== actualType && actualType !== 'RELACIONAL') {
            this.errors.push({
                type: 'Semántico',
                msg: `Incompatibilidad de tipos: Se esperaba '${expectedType}' pero se obtuvo '${actualType}'.`,
                line: line,
                column: col
            });
        }
    }
}
